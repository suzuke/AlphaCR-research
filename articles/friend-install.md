# 朋友版：下載兩個檔案，雙擊安裝

第一次請對「安裝.command」按右鍵 →「打開」。試玩包沒有 Apple 簽章；之後可以雙擊使用。若仍被 macOS 擋下，先嘗試打開一次，再到「系統設定 → 隱私權與安全性」允許打開，然後重試。

> 草稿，尚未發布：zip 將放在 AlphaCR-research 的 GitHub Release，任何人都可下載。目前尚未上傳。瀏覽器下載後的首次 Finder 開啟流程仍待人工驗收。

## 準備兩個檔案

需要 Apple Silicon（M1 以後）的 Mac，macOS 15 以上。不需要 Xcode 或 Homebrew。

| 檔案 | 放哪裡 |
|---|---|
| AlphaCR-research 的 GitHub Release 提供的試玩包 zip | 下載後解壓縮 |
| 你自己取得的 Nulls 15.535.13 APK（Android 安裝檔） | 放在「下載項目」：`~/Downloads`，且只留一個 `.apk`；檔名不用改 |

我們的包不包含遊戲檔案，也不會代你下載 APK。其他版本會被檢查擋下，改檔名也不能使用。下載項目裡只留一個 `.apk`，檔名不限；版本由檔案雜湊檢查把關。

## 安裝一次

1. 解壓縮 zip，打開 `AlphaCR-package` 資料夾。
2. 右鍵「安裝.command」→「打開」。腳本會把整包搬到家目錄的 `AlphaCR-package`，解除隔離屬性，再尋找 APK。
3. 終端機顯示連線資訊後，自己確認並輸入 `yes`，按 Return。輸入其他內容就不連線。
4. 在遊戲視窗自己註冊或登入私服帳號，等待內容下載與逐檔檢查。不要點商店、付費、寶石或 Pass；登入時也不要按 Esc，它會結束視窗。
5. 看到 `Installation complete` 就裝好了。終端機最後顯示本次紀錄檔的位置，按 Return 結束。

這次下載是唯一會連網的步驟。連線白名單與下載檔案檢查照常生效；遊戲資料保存在 `~/AlphaCR-friend`。

## 之後直接雙擊

在 Finder 打開家目錄裡的 `AlphaCR-package`：

| 雙擊哪個檔案 | 做什麼 |
|---|---|
| 開始玩.command | 你對模型，選牌後開始 |
| 模型對模型.command | 觀看模型自己對打，可選雙方牌組 |
| 重播最近一場.command | 重播最近一場打完的模型對模型 |
| 錄影最近一場.command | 把最近一場模型對模型錄成 MP4，可能需要幾分鐘 |

這些玩法都在本機執行，不連網。視窗對局結算按 OK 會回選牌畫面；選牌時按 Esc 或關閉視窗即可結束。
對戰紀錄與影片在 `~/AlphaCR-friend/runs/friend/`。

## 安裝停下來時

| 畫面訊息 | 怎麼處理 |
|---|---|
| `No APK` | 確認副檔名是 `.apk`，並放在下載項目，再開家目錄裡的安裝腳本 |
| `Multiple APK candidates` | 依列出的檔名，在 Finder 把多餘的 APK 搬到別處，只留一份 |
| `already exists; nothing was replaced` | 家目錄已有另一份包；要重試舊包就開舊包的安裝腳本。要換新版，先把舊包搬到別處再開新版 |
| 更新內容缺檔 | 重開家目錄裡的安裝腳本重試；仍失敗就回報 |
| APK 或更新內容不符 | 先確認版本；請回報錯誤，不要跳過檔案檢查 |

每個雙擊入口都把終端機畫面存到 `~/AlphaCR-friend/logs/`，成功與失敗都會顯示檔案位置。紀錄可能包含本機路徑與連線資訊；回報前先查看，不要把帳號資料或完整未檢查紀錄公開上傳。

## 版本與下載校驗

zip 會公開放在 AlphaCR-research 的 GitHub Release，任何人都可取得。版本以 release tag 標示，例如 `friend-v1`；實際 tag 以發布頁為準。

發布時，Release 說明與本頁會列出同一份 zip 的 SHA-256 校驗值，用來核對下載檔案。最終包須先整合下載修正並通過驗收，目前不填入舊包的校驗值。

| 發布資料 | 狀態 |
|---|---|
| Release tag 與下載位置 | 待發布時填入 |
| zip SHA-256 | 待最終包驗收後填入 |

公開 repo 只收錄這份安裝說明，不另外收腳本；五個雙擊腳本都在 zip 裡。
